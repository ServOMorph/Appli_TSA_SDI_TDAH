TA QUESTION EN COURS A MARIE
Le pending est enregistre. Des que Marie repond sur Discord, l'agent DISCORD route sa reponse
vers gateway/inbox/orchestrateur/ et purge le pending. Tu la lis avec :

  python DISCORD/discord_com/gateway.py poll --agent orchestrateur
  python DISCORD/discord_com/gateway.py ack  --agent orchestrateur --id <id>

API RAPPEL

  # envoyer
  import sys; sys.path.insert(0, "DISCORD/discord_com")
  import gateway
  gateway.enqueue("orchestrateur", "marie", corps, kind="question", expect_reply=True)

  # recevoir
  for msg in gateway.poll("orchestrateur"):
      traiter(msg)            # msg["content"], msg["from_discord"], msg["routing"]
      gateway.ack("orchestrateur", msg["id"])

Champs message inbox : id, from_discord{author_id,author_name}, content (corps sans le tag),
raw_content, routing (tag|pending|heuristique|aucune), reply_to, received_at.
Pour forcer le routage d'une reponse Discord vers toi : que l'expediteur prefixe « @orchestrateur: ».
