# Étape 8 — Créer le runner du Flux A

Créer `ROBERTO/workflow.py` avec une fonction `traiter_entree(entree: dict, action: str) -> dict` qui **enchaîne réellement les transitions à partir de l’état courant** : `RECU → ANALYSE`, puis selon `action`, `ANALYSE → CORRECTIONS` ou `ANALYSE → INTEGRE`.

Ajouter `ROBERTO/test_workflow.py` pour vérifier les deux parcours complets jusqu’à `CORRECTIONS` et `INTEGRE`, sans mutation de l’entrée originale.
