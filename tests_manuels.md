# Tests manuels en attente

## Phase V5-3 — Outils, dossiers, listes et budget rebranché

1. Installation neuve : vérifier que la To Do et le Budget apparaissent d'office dans les outils (accueil + écran Outils), sans aucun élément préchargé dedans.
2. Créer un dossier depuis le « + » des outils, puis une liste à l'intérieur ; vérifier la navigation dossier → liste → retour.
3. Dans une liste : cocher/décocher un item (tactile réel), vérifier que les cochés descendent sous les non cochés, tester une rubrique.
4. Réveil sur un item de liste : planifier une tâche ponctuelle et une récurrente, vérifier qu'elle apparaît bien dans le planning déplié à la bonne date/heure.
5. Widget Comptes sur l'accueil : saisir une dépense en un tap, vérifier la mise à jour dans le Budget.
6. Vérifier que le Budget reste pleinement fonctionnel (catégories, comptes, dépenses, dépôts) inchangé depuis sa nouvelle porte d'entrée.
